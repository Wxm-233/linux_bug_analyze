## 结论边界和下一步

N2.16中“直接源码候选依赖未展开include”的缺口，现可在新重建层级具体展开；旧运行仍缺当时完整CPP/环境和编译链接的直接来源记录。本轮不改写旧binding结果，不把新CPP回填成历史运行来源证明。whole_path、实际首次内容消费、初始化/物理值及稳定窗口均保持不足。

自动部分：按实际命令重建CPP、源码/生成输入身份、宏生效轨迹、有限宏体/来源核对、完整表项及契约关系。人工部分：规范权威、版本和用途政策、宏体含义、组及对象角色、合法比较和支持域。N1自动推导要求尚未完成；统一检查器尚未建立。
