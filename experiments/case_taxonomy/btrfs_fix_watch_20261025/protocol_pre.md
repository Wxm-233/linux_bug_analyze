# 修复版对应监测对照

冻结父版采集器/核验器、区间适配器、运行事实与操作数解析器。新采集脚本只改独立磁盘名；准备改为修复版源码/构建并独立编译offsetof及查实际符号。核验脚本只改运行context与对应修复基线。先冻结后运行，不根据修复结果修改检查条件。

使用原修复观测Image、相同initrd和同SHA空白盘克隆，单CPU QEMU TCG、相同nokaslr调试参数。两个max_inline选项区间监测super.sectorsize和info.super_copy，并以info.max_inline自然写作为正控制。与父版比较是同一已读修复家族的开发对照，不是独立正常样本。

所有结果如实记录；无写命中不自动等于全局稳定；目标点、别名/DMA及未运行路径边界不变。预计缓存准备值不同，但适配器不以旧版4096或修复65536作路径准入。C和whole_path仍不足，不新增模型调用。
