局部整数别名每轮进入/退出作用域；直接返回和初始化0、仅置1的累计标志分别表示。记录实际检查条件与本轮此前执行的数组写次数，区分写前/写后、首个匹配、提前退出和continue缩小的访问域。写入次数本身不证明写入和检查是同一对象；返回码也不作为系统错误标签。
