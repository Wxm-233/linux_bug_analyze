## 驱动做什么（说人话）

以前的入口只要找到缓存文件就用。某个版本缺 EC 结果时，它还会把 df 的结果复制过来顶上。这样表能出来，但不一定是那个版本的。

现在的驱动对 9 个引擎的缓存逐个核对：缓存里记的版本是不是目标版本、引擎有没有报错、文件能不能读。三项都过才用。
- 缓存缺了，就调用引擎原来的命令生成；
- EC 目前只能为 df 生成整版结果，其他版本明确写“缺失”；
- 版本对不上就“拒绝”。

**任何情况下都不复制，也不把缺失当成 0 条。** 每次运行都会写一份运行清单 `manifest.json`，内容包括：
- 每个引擎的缓存路径、SHA256、缓存版本、状态、来源（已有缓存 / 本次生成）；
- 产生缓存的引擎脚本的 SHA256；
- 整张表是否完整，以及用时。

用法（WSL）：

```
python3 drive.py scan <版本> [-j 8] [--no-generate]
```

结果写到 `out/<版本前12位>/`，包括 `table.csv`、`table.json`、`table.md`、`manifest.json`。
