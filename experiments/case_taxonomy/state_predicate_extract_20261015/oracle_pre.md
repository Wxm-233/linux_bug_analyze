# 研究侧分层评估，不供模型、runner或适配器读取

已读接口的开发预期：状态关系与来源资格应比只提前某调用更具体。参考既有研究侧窄条件是公共首次锁消费时当前CPU属于其mask；online不等于准备，nonempty和weight1也不保证目标成员。若模型只给较弱的必要条件，应如实保留其价值与覆盖边界，不能因未给self就记格式失败或自动认定无价值。

模型可能给出其他合法必要关系，按原文及条件审定。每个AST保留原样，不补研究侧条件；未知或不可映射照实记录。paired需真实两侧提供者与配置依据，ablated不能凭空指定架构违约。仅在对象/时点绑定后复用归档观测，四格一致不是独立泛化。逻辑反例只是说明弱检查的局限，不是新内核运行。
