# 判据修订1：第二标注人改为GPT（看复核结果之前写定）

## 改了什么

`criteria.md`第五节规定由“第二人”独立复核随机抽取的40条（`second_sample.json`）。用户决定由GPT担任第二标注人。

## 需要如实说明的事

- **第一遍标注也是由模型（Claude）完成的**，此前各轮记录中写作“研究者”。因此这次复核得到的是**两个不同模型之间**的一致率，不是人与人之间的一致率，也不能替代人工复核。报告时照此写明。
- GPT只能看到我们给它的材料（提交说明和改动），不能在内核仓库里检索。因此“对应物位置”一项只作参考，**一致率只统计“跨架构C/R”和“机制”两项**。

## 怎样做

- 材料、说明和答题表放在`second_review/`，其中不含第一遍的标签；答案保存在`second_sample_key.json`，不交给GPT。
- 用户把`second_review/`中的说明和材料交给GPT，GPT按说明填写答题表，用户把填好的表放回`second_review/answers.csv`。
- 用`score_agreement.py`计算：
  - C/R的一致率和Cohen's kappa；
  - 机制（M1–M10、X1、X2）的一致率和kappa；
  - 列出不一致的条目，供人工裁决。
- 不一致的条目只记录，**不修改已冻结的`labels.json`**。若裁决后认为第一遍标签有误，另写修订文件说明。

## 参考线（只用于描述）

C/R的kappa不低于0.6记为“一致性较好”，0.4到0.6记为“中等”，低于0.4记为“较差”。
