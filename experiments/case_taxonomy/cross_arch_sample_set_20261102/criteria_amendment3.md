# 判据修订3：按收紧后的定义再做一次第二人复核（抽样之前写定）

## 为什么

第一次复核的40条已经参与了修订1和修订2的讨论，再拿它们算一致率会偏高。所以按修订2收紧后的定义，**换一批没用过的40条**重新复核，检验收紧后的定义是否更容易被独立地一致执行。

## 怎样做

- **抽样**：从`labels_v2.json`中留下的条目（去掉“无关”），**排除第一次复核的40条**，用`random.Random(20261103)`抽跨架构C 20条、R 20条，打乱顺序。
- **材料**：放在`second_review_v2/`，格式与第一次相同，说明改为修订2的规则；不含第一遍标签。答案存为`second_sample_v2_key.json`，不交给第二标注人。
- **第二标注人**：仍由用户交给GPT，新开对话。
- **评分**：与第一次相同（C/R和机制的一致率、Cohen's kappa、不一致条目），与`labels_v2.json`比较。
- **对照**：报告时与第一次复核（kappa 0.55）并列，只作描述；两次样本不同，不做显著性检验。
- 不一致条目只记录，不修改`labels_v2.json`。

## 参考线

与修订1相同：C/R的kappa不低于0.6为“一致性较好”，0.4到0.6为“中等”，低于0.4为“较差”。
