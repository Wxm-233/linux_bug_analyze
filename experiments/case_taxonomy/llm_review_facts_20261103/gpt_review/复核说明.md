# 复核说明：程序规则标出的问题是不是真问题

`items.md`中共18条。每条都是一个程序规则在某个Linux内核版本的RISC-V代码中标出的问题，附有规则说明、位置、理由、调用链和当时的代码。

请判断每条在**它所写的那个内核版本中**是不是真问题，选一个标签：

| 标签 | 含义 |
| --- | --- |
| `real` | 真问题：确实会导致错误行为、警告误报、安全问题，或违反内核约定 |
| `false_alarm` | 不是问题：例如路径走不到、锁已释放、下标不受不可信方控制、只是缺少某项功能或优化 |
| `unsure` | 判断不了 |

可以使用你对内核的了解。理由写一句话。

填写`answers_template.csv`，另存为`answers.csv`：保留表头和第一列，不改变行的顺序。
