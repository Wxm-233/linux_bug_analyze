## 评审前复核（replay_results.json）

- 归档完整性：三轮最新目录按各自交付清单逐文件核SHA，126/120/88项全部一致；六个旧轮次无交付清单，仅记录当前README/结果SHA快照，不当作旧完整性证明。
- 契约重放：用不变公共核心（SHA `42d37cc4…`）重放已保存的164个契约输入——ARM64正常20项全满足、旧SPARC适配器回验24项（20满足/4违反）、双位宽投影120项（89满足/16不适用/15违反），与原记录逐项一致；账本引用的证据文件SHA均未变。
- 对象层判定：16项按最终判定器重算与原结果一致。
