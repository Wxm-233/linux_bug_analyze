# 自测期望集的更正（2026-11-09）

第一次运行（`result_first_run.json`）：6 条期望全部报出，另外多出 1 条：

- `("arg-diff", "arch_flush", "log_only#0:['1']vs['3']", "arm64")`

核对：样例里 riscv 的 `arch_flush` 调 `log_only(1)`，arm64 的调 `log_only(3)`。两边都直接调用同一个纯公共函数 `log_only`，位置 0 上的常数实参集合 {1} 与 {3} 不相交，按判据 3.3 的 `arg-diff` 条件**应当报出**。

原因是我写样例时，三个架构的 `arch_flush` 随手用了不同的常数，写期望集时只想着这个家族要测 `call-missing`，漏了判据同样要求的这一条。工具的行为符合判据，错在期望集。

更正：在 `EXPECTED` 中补上这一条，其余不变。没有改判据、样例代码和工具。
