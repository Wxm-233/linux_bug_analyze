# N2.7 独立限域复核（2026-10-17）

结论：未见阻断问题。`protocol_pre.json`将本轮登记为 N2.6 格式失败后的后继开发，且限定为合成格式连通性；不能用它追认 E/F 的失败输出或证明跨架构研究效果。

`schema_instruction.py`从单案例 packet 的 `case_parents` 和每份文档身份形成实际 `case_parent` 材料组，拒绝混组、重复/保留文档 ID 和版本不一致；不从架构名推导配置。生成说明列出 `document/start_line/end_line` 精确键、非 bool 整数、完整文档 1 起始行号、每段≤24行，并明确不接受 `lines` 字符串与 `CASE_parent` 占位。Q、Trial_2 两组合成输入显示 profile 确实分别实例化。专用 `__FORMAT_ONLY__` 文档不列入真实 allowed IDs；提示文案反复标明只能演示字段，不能照抄为案例证据。不过真实答复仍可能机械复制首行 `evidence_example`，应继续由原检查器核引用与语义审阅，格式说明本身不是事实认证。
