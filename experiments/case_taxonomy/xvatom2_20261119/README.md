## 改了什么

1. **只认作用在页表项指针上的原子操作**：从成员的项指针形参出发，经过强制转换别名（`(atomic_long_t *)ptep`、`&pudp->pud`）往下追。只有实参里带项指针的调用才往下追；原子原语的实参里要出现项指针，或者带项指针的函数里有原子汇编。
2. **深度不设上限**，只防循环，链长 12 层封顶。
3. **修订 1**：`buddy->pte` 这种字段名、`ptep->pte_high = …` 这种字段赋值，不算项指针。
