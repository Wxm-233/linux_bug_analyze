## 用法

都在 WSL 里运行。从 Windows 调用：`MSYS_NO_PATHCONV=1 wsl.exe -u root bash /mnt/d/.../heldout2_base_20261119/run.sh <命令>`。

| 命令 | 作用 |
|---|---|
| `jobs` | 列出任务数，按引擎拆分为待跑 / 完成 / 出错 / 写坏 |
| `runall 4 4` | 跑缺缓存的任务，P1/XV 最多 4 个并行，其他引擎最多 4 个。日志写 `runall.log`，各引擎的输出写 `engines_output.log` |
| `stop` | **暂停**：运行器停止派发，杀掉进行中的任务（按进程组），删除写坏的缓存，然后退出。命令会等到全部停下才返回，并报告剩下几个引擎进程（应为 0） |
| `status` | 已完成、出错、待跑的任务数，以及运行器是否在跑 |
| `score` | 评分。分析集写 `results_analysis.json`（逐样本）；封存集只写汇总 `summary.json`，逐提交报告写进临时目录，评完就删 |

**续跑**：再执行一次 `runall 4 4`，已完成的任务不会重跑；被暂停打断的任务从头重跑。
