# 修订 2：内核控制台消息插进测试输出行（解析工具错误）

2026-11-09 21:35，Claude。写于动态复测（判据 4.4）运行完成、`compare.py` 处理到第 5 组时报错之后。此时我**已经看到** A101、A310、A171、A181 四组的比较汇总（每个 riscv 内核上一致、不稳定、与众不同的计数），**还没有看任何检出或评价结果**。

## 发现

`b467_ref_x86_64.run2.log` 第 22 行：x86 内核在启动后约 2.9 秒异步打印了一条驱动消息（`psmouse serio1: pixart_ps2: init: Unable to query PixArt touchpad hardware.`），正好插在执行器输出的一条 JSON 结果中间，这行 JSON 被分成两半，解析失败。上一轮 69 份日志里没有出现过。

## 处理

- 本轮 `compare.py` 在调用上一轮的 `parse_log.py`（未修改）之前，先做一次预处理：删除出现在一行中间、以内核时间戳 `[  秒数.微秒]` 开头、直到行尾的内容。这样被打断的 JSON 的前后两段重新接成一行。
- 预处理对所有组、所有日志一律适用，不只针对这一份。被修复的行数写进 `runs/<组>/compare.json` 的 `repaired_lines`。
- 若仍有解析失败，照常报错停下。

其余判据不变。
