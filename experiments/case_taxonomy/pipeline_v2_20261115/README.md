## 局限（如实写明）

1. **规则映射很粗**：只看效果类别和资源变量名。例如 `move_ptes` 的资源叫 `new_ptep`，不在名单里，就被归为“内核内部”转了人工；它其实是页表项，R2 的 T 系列可能检查得到。
2. **覆盖表是手写的**：13 个模板经过哪些函数，是我读代码路径后写的，不是从运行中测出来的。
3. **转人工的建议很简略**：现在只写了资源、性质和“需要 ACTOR 或调试内核”，没有写建议怎么查。前几轮的人工建议模板（`effdep5` 的 `out/*_suggestions.md`）可以合进来。
4. **只接了纵向信号这一种静态输出**：类型一致性、调用上下文检查的输出还没接进同一张报告。
5. **端到端只验证了 X1**：它又是设计方法时参照的例子。当前版本没有确认项，这只说明没有误报，不说明能发现新问题。
