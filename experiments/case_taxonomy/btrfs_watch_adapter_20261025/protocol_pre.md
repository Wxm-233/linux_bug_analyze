# 内核区间证据适配器：执行前约定

复用上轮1次内核运行的原件，冻结prepared.json、runtime/rsp.jsonl、boot/super/tree、compiled/offsets.s及原观测解析器和通用核心。新代码只重放已登记的AArch64单CPU RSP采集序列，不支持任意GDB日志。

从原始协议逐步导出入口寄存器、选项、对象、目标安装、自然写控制及返回PC/SP，核对启动日志操作数；不将旧results.json的“0命中”字段当输入事实。两个重用同地址的挂载必须形成不同事件ID。严格协议限制意味着不支持的合法变体也会拒判，不能声称通用性。

外层固定原件SHA；内层用显式内存变异控制检验错对象、错入口/返回/SP、未安装/失败安装、单步中撤目标、缺正控制、截断及尝试消费期限提升。两者分开统计，不将同一SHA失败当所有结构检查有效。

输出仅为“登记虚拟范围内的无目标写记录已校验”。C/whole_path保持insufficient；不填disk_at_deadline、不自动批准条件前提，不修改旧统一核心。无模型调用/内核启动，不增加独立案例。
