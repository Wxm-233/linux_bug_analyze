# D1 / N2.25：表示类接口的首个迁移工作单元

2026-10-23。已完成一个已读ocfs2工作单元的有界材料审查。**局部“存储格式→主机位判断”可用于最小迁移设计；完整写读链、实际文件系统触发与统一方法有效性仍未通过。** 本轮没有运行实验或项目模型，没有增加确认缺陷或独立样本。

## 为什么选它

现有ocfs2材料保留了字段声明、端序接口、公共使用、条件性buffer来源、后续union消费和正常读取。相比之下，bcachefs2007d更偏同版本字段名/编译兼容，3f3涉及布局/对齐。只按既有摘要完备度选ocfs2，不扩成多案例。本例早已读补丁、做缩小原型、开发专用规则，并于10/03复核；原packed扫描零站点的历史失败不改写，不称盲测。

唯一primary为父版`390ac56cf0f687de53695648bc6f2259a7eae429`的`ocfs2_dinode_has_extents.i_flags`。复用九份父版原文件，路径/SHA见[source_reuse.json](source_reuse.json)，不复制全文或补取新源码。

## 架构因果链与局部检查卡

| 项目 | 本轮核对内容 |
| --- | --- |
| 接口依据 | 同版`ocfs2_fs.h:660–678`说明盘上inode，i_flags为__le32；:207–221定义标志，:726–735说明id2为多用途union。依据来自格式和用途，不以补丁或多数架构为准 |
| 架构条件 | 磁盘格式固定小端；不同主机端序解释相同字节时得到的本机整数不同。两套byteorder头对转换给出恒等/交换语义；本轮未构建实际CPU配置 |
| 公共消费 | `inode.c:204–205`直接以普通整数掩码判断i_flags；这会决定是否将id2当extent list。:1637–1649连接到同di的记录边界比较和可能修改 |
| 隐含要求 | 同一字段的位存在性判断，应与先按存储格式解码、再检查主机语义掩码一致。转换字段或转换掩码均可能满足要求，不能只搜有没有le32_to_cpu |
| 不同暴露 | 小端条件下直接字段值与解码值相同，遗漏转换可能被掩盖；大端条件下相同公共表达式可能判断错误位。下游影响仅在全部入口/修复条件成立时发生，本轮未观察真实损坏 |
| 检查位置 | 在类型标志决定union解释之前，核字段宽度/存储域、掩码域、操作和转换关系；比较的是所选读取的语义，不是不同架构原始数值必须相同 |

局部形式可写为`bool(actual_field_operation) == bool(decode_le32(field) & host_mask)`。这个式子是研究者按源码登记的要求，不是现有程序自动提取的结果；有条件的局部关系也不证明整个函数正确。

## 正常参照不能混为一类

1. **最接近的同用途参照：同一primary的小端语义条件。** 转换恒等，所以同字段、同位置、同目的的判位具有积极局部保证。它仍是同一个已读案例的开发对照。
2. **同字段、同表示掩码：** 父版`inode.c:403`先将LOCAL_ALLOC掩码转成小端，再与i_flags相与，说明并非所有直接读取都错。它在另一个调用点，只能作每次读取的正常参照。
3. **零判断：** 同函数i_size非零与i_clusters等于零对完整字节置换保持真值，可检查规则是否过宽；同一条件中的i_mode及全函数不因此正常。

## 完整路径仍缺哪些证据

源码支持有条件的filecheck入口→read/callback→bh->b_data/di→primary→id2消费。缓存、journal、只读、验证及有效位等条件会改变可达性；Kconfig/Makefile这里只给静态范围，没有实际解析配置、挂载及非空filecheck运行实例。

也不能说“清单内没有写者”：`inode.c:766`确有按小端表示清除i_flags位，buffer层也有WRITE。但它们没有闭合本次primary特殊类型位的创建、写入、存储和该次读取。validate中的meta-ECC helper可修复数据，其效果未纳入本清单；“本段没有显式写i_flags”不能证明初始磁盘值一直不变地到达primary。

因此本轮只审准非空局部字段语义域。该域不是合法整块盘面、可挂载inode或真实修复路径的见证，**完整写读/运行门控保留不足**。

## 方法现在实际支持什么

现契约核心可以比较外部已经投影的bool/int，尚无位运算、字节编码或byteswap；CPU归档适配器不适用，旧endian专用checker也不能充当统一迁移成绩。把人工填的布尔答案交给核心再得到相同结论，不能算自动检查进展。

下一步需要先固定一个通用、有限的表示事实投影协议：明确字宽、存储/主机端序、实际操作和掩码的来源；支持域外返回不足。核心复用与新增投影分别评价，规范、用途及复杂路径的人工部分单列。
