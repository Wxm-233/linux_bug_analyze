# Claude 接口只读诊断（2026-10-15）

本复核只检查最终正文及 HTTP／SSE 协议元数据；未读取或解释非最终推理字段，未调用 API、访问密钥或修改既有响应／账本。

## 现象与证据

| 请求 | 可确认结果 | 服务端用量与时间 |
|---|---|---|
| `probe_nonstream` | 标准库直接 HTTP；200、型号一致、`stop`，有效最终正文 | 35 token；7.948 秒 |

| `loops` | 标准库直接 HTTP；200、型号一致、最终正文为空，**`finish_reason=length`** | 输入 3,826、输出 4,096、合计 7,922 token；117.447 秒 |

`loops` 的原始 HTTP 响应在 [loops.body](responses/loops.body)。只选择允许的元数据核对后：

- 324 个 JSON SSE 事件，1 个 `[DONE]`，无 JSON 解析失败；型号唯一为 `AWS-Claude-Sonnet-5`，选择索引唯一为 0。
- 322 个事件显式 `content=""`，另 2 个未含 `content`；没有非空最终正文。
- 全部事件均未出现 `refusal`、`tool_calls`、`function_call`；没有非空 `moderation` 或 `error` 元数据。
- 结束原因只有一次，值为 **`length`，不是 `stop`**。输出用量 4,096 恰好达到请求的 `max_tokens=4096`。
- 用量细分记录 `reasoning_tokens=785`、`text_tokens=3311`。这些只是服务端记账元数据，不能据此推断存在可用最终正文或将其他通道内容充作最终回答。
- 响应头 `X-Oneapi-Request-Id`：`202610150652253728642648268d9d6tZqKJgiW`；Content-Type 为 `text/event-stream`，Server 为 nginx。

请求 [loops.json](requests/loops.json) 使用 4,096 输出上限、temperature 0.2、stream=true、include_usage=true；两条消息分别 260 与 6,832 字符。这个约 3.8K 输入 token 的小源码请求仍为空，不能简单归因为此前约 18K 的大包输入。

## 能确定什么

1. 当前密钥、模型名、基本路由在两次极短诊断时能够获得有效最终正文；不能把所有请求失败统称为接口不可用。
2. `loops` 已绕过 OpenAI SDK，原始 HTTP 的最终 content 本身为空。因此本次空正文不能归因为项目 SDK 把已有最终正文吞掉。
3. 本次确实触及单请求输出上限；它与上一轮 `stop`／1 输出 token 的空答是不同现象，应分开记录。
4. 本地 WSL 安装为 `openai 3.8.0`，声明依赖 `httpx2`，当前 `httpx2 2.12.0` 已安装；`httpx` 模块不存在不代表 SDK 缺乏 HTTP 支持。六个关键 SDK 源码文件与本地安装 RECORD 一致，未发现按模型名转换最终正文的本地自定义实现。这里只确认本地结构和记录一致，未联网鉴定发行来源。

## 目前不能确定什么

- 没有可见的拒绝／过滤错误字段，不能据此认定内容过滤、某个关键词、平台安全策略或账户余额导致空答；字段缺失也不能绝对排除上游转换问题。
- 既然 `loops` 结束于 `length`，不能声称输出额度完全无关；但也不能保证调大上限就一定会出现最终正文。
- 请求大小、输出上限、流式与材料内容没有做受控单变量实验，不能从这几次结果推断一般输入长度阈值或稳定故障原因。
- `consumer` 没有响应和可核验用量，不应将它记成有效分析、确定性拒绝或零消耗。

## 后续处理边界

保持原始响应和账本不变。当前尚无有效的 consumer／loops 研究结论，不启动依赖它们的架构审查、反例复核和综合请求，不用无最终正文的其他通道替代结论，也不循环重发。

如后续排查平台，可凭上述 request-id 和只含最终协议的现象说明核对上游输出映射／结束原因；若另开提高单请求输出上限的试验，应作为新的有记录请求，而不是改写本次 `length` 结果。本轮研究仍可继续进行本地原函数与反例对照，并明确标记为程序／研究侧分析，避免冒称 Claude 已完成深入复核。

截至本复核，两次 probe 已知用量 79，`loops` 已知用量 7,922，`consumer` 未知预占 52,146；与旧累计 221,927 相加为 **282,074 / 1,000,000 token**（其中 150,612 为未知用量预占）。这说明当前累计预算尚有空间，但不能用预算剩余推导任一单次请求应当成功。
