# 执行前限定与记录修订

尚未编译或执行。实际计划只有 experiment_pre.json 的 NR_CPUS=8、64位字、六种输入状态乘两版本共十二组合；源码审阅所列 NR64/128 和反序枚举是备选建议，没有采用或运行，不累计为额外覆盖。

公共头通常要求 CPU 编号小于 nr_cpu_ids；本轮只沿 NR_CPUS 不超过字宽时的八位源码操作，投影早期数量限制与后续重定界，不据此证明中间高位是普遍合法 API 使用、合法 SPARC 配置或设备树。多字/动态位图分支不纳入。模型原始 subset/last 对应头中同为 small_cpumask_bits，当前分支取八位；不把该原始谓词当金标准。

初始 online={0} 只描述引导背景，当前原函数并不读取或写入 online，宿主代码也不模拟在线 CPU 状态。只具体实现 possible、present、ncpus_probed 和本地 nr_cpu_ids；不存在真实 CPU 启动、分配、锁或并发。

身份关系限定在已读 SPARC 回调把固件 cpuid 直接用作公共位图索引的同一命名空间。其他架构可以通过显式硬件到逻辑编号映射合法生成不同编号；不能把本轮“输出属于输入身份集合”的原始子集检查直接套到 ARM64。可复用要求必须连接所选输入与该架构的映射结果，并核对映射后的身份，而不是要求所有架构使用相同原始编号。本轮没有执行另一架构的映射或配对。

方法审阅后只补 runner 的首失败记录：gcc版本探测放入受保护执行块，每次调用在发起前登记argv，超时保留partial stdout/stderr，启动失败保留错误。不修改源体、API摘要、固定输入、事前预期或原正式组件，没有因结果而修订。
