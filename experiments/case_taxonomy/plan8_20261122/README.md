## 二、我的方案

**采纳 astra 的五轮安排和顺位**，补几处具体判断：

1. **第一轮（约定供给）先做**。我预计页帧号往返能过线：`pte_basic_tests` 用 `pfn_pte` 构造过固定页帧号，但断言没有比较全部页帧号位；pgassert 的“构造输入”里已经有 `pfn_pte` 的求值经验。需要提前注意的难点是：x86 的 `__supported_pte_mask`、`sme_me_mask`，以及 arm64 LPA2 的页帧号布局，涉及全局量和运行时判断，要在判据里写明怎么建模；做不了的部分如实记“不支持”。

3. **原生测试体检（第四轮）里，loongarch 误报要先在 QEMU 上真正启动一次**（`qemu-system-loongarch64` 加 `DEBUG_VM_PGTABLE`），把“clang 折叠”升级为“实际启动观察到”，再决定是否登记。
