```
spin_lock(&l); if (x) { spin_unlock(&l); y(); } arch_sleepy3();
```

- 第一版（修订 1 语义）认为：分支里的解锁后面没有 goto 或 return，就算结束，所以 `arch_sleepy3` 不在锁内，不报。
