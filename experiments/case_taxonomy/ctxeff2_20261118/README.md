## 改了什么

1. **区间按花括号层级配对**：解锁只结束同一层级打开的区间；更深一层分支里的解锁，**暂停**外层区间，直到同一层重新加锁，或者该分支结束（修订 2）；分支里加的锁，只在分支内有效。
2. **在会睡眠的函数处截断传播**：被调函数自己直接调用了睡眠原语（`might_sleep`、mutex、GFP_KERNEL 分配等），就不再把原子上下文传进去，也不经由它继续向下传。
