## 对“问题出在方法还是接口信息”的回答

- 只用“S的diff里哪些通用接口被其他架构使用”这一条接口使用信息，不看任何文件结构，前20就覆盖了25/50，与结构基线B3（26/50）相当；两者重叠不多，B3漏掉的对里API补回7对。
- 因此，P1/P1′的失败主要在“让模型写全局正则”这一做法；而**接口使用关系是有效的信息**，与结构对应互补。早期契约路线缺的正是这类可以自动得到的跨架构接口使用关系，而不是更细的契约描述。
- 仍有限制：只有50对，而且是开发集；66%差一点没达到事先门槛；前40的候选数对逐项判定来说已经不小。
