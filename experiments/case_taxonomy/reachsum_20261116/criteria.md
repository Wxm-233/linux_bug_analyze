## 一、要解决的问题

有些函数在入口查 present，不 present 就返回一个固定值，调用者检查返回值后跳过。例如：

```c
page = can_gather_numa_stats(ptent, vma, addr);   /* 非 present 返回 NULL */
if (!page)
        continue;
gather_stats(page, md, pte_dirty(ptent), 1);      /* 这里 ptent 一定 present */

pfn = get_pte_pfn(ptent, vma, addr, pgdat);       /* 非 present 返回 -1 */
if (pfn == -1)
        continue;
```

现在的分析器只认直接写在调用点上的 `pte_present()` 等守卫，看不到“守卫写在被调函数里、经返回值传出来”的情况。`reachf1` 的事后探查里有 3 条属于这种（`can_gather_numa_stats`、`can_gather_numa_stats_pmd`）；`reach_20261115` 人工排除的两条 MGLRU 路径（`get_pte_pfn`）也是。

## 二、摘要（写死）

对扫描范围内只定义一次、有返回值的函数 g，以及它的每个类型含 `pte_t` 或 `pmd_t` 的参数 p，判断是否满足“**g 的返回值不等于 v，则 p present**”：

1. 收集 g 里每条带表达式的 `return` 语句，以及语句处成立的事实（同一分析器，含 if/else、提前返回、循环条件）；
2. 一条 `return` 算“已守卫”，当且仅当那里有事实：F1 名单里的谓词（含本轮已得到的摘要）对 p 为真。p 是值参数时，事实对象是 `p`；p 是指针参数时，事实对象是 `*p`；
3. 摘要成立的条件：
   - 至少有一条未守卫的 `return`；
   - 所有未守卫的 `return` 都返回**同一个字面常量** v，v 是 `NULL`、`false`、`0` 或整数字面量（如 `-1`）；
   - 已守卫的 `return` 返回什么都可以。
4. 摘要可以嵌套（g 依赖另一个摘要函数的返回值），最多迭代 3 遍：每遍算出新摘要后重新分析全部代码。

## 三、在调用点上使用（写死）

摘要 (g, p 的位置 i, v) 生效后：

- 调用 `g(...)` 产生的事实，对象取第 i 个实参的规范来源；p 是指针参数时，在前面加 `*`；
- 下面几种写法都得到“g 为真”，也就是 p 对应的实参 present 的事实：
  - `if (g(...))` 的分支内，`if (!g(...)) return/continue/...;` 之后；
  - `x = g(...)` 后的 `if (x)`、`if (!x) 退出`（v 是 `NULL`/`false`/`0` 时，分析器已有的布尔别名机制）；
  - `x = g(...)` 后的 `if (x != v)`、`if (x == v) 退出`（本轮新增，v 是任意字面常量）。
- F1 名单 = `reachf1` 的名单 + 全部摘要函数。
