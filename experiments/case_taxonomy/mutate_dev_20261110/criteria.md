# 判据：合法基础用例＋单点变异（mutate_dev_20261110）

2026-11-10，Claude 在实现之前写定，SHA 存入 `criteria_sha256.txt`。本轮属于开发集，允许发现自己工具的错误后写修订。

## 一、要回答的问题

上一轮（`casemodel_dev_20261110`）的诊断表明：多个条件随机同时满足的概率是相乘的。`recvmsg` 的 fd 取到带控制消息的数据报套接字只有 3/139；B467 需要“size 正确、只改 type、group_fd 为 −1、flags 为 0”同时成立，从未凑齐。

本轮改成：先为每个系统调用找到合法的**基础用例**，再每次只改一两处。回答：
1. 这样能否检出 B467，以及更稳定地检出 A101、A181？
2. 静态定向和提示在这种生成方式下有没有作用？

## 二、基础用例（规则写死）

- **候选**：对全集 U 中每个系统调用（raw_nr 除外），用固定种子生成 48 个候选。第 1 个候选每个参数都取第一个选项，其余 47 个每个参数在选项中随机取。各参数类的选项：

| 参数类 | 选项（按顺序） |
| --- | --- |
| 结构体指针（三个架构都有布局） | 结构化缓冲区（按上一轮 C1 填指针、长度、`size` 字段，**不随机改写标量字段**）、全 0 缓冲区、NULL |
| 其他指针 | 全 0 缓冲区、0xAA 缓冲区、NULL |
| 路径 | `/tmp/f`、`/tmp/d`、`/tmp/nonexist` |
| fd | 上一轮的全部 17 种（名为 dfd 的另加 AT_FDCWD）；参数名在资源表里的，资源排在第一个 |
| 资源类参数名（`msqid` 等，上一轮 C3） | 对应资源、0 |
| 大小/长度 | 64、4096、16、1、0 |
| 标志/模式/命令 | 0，以及词表（上一轮 C2）中的前 4 个枚举值 |
| pid | 自身、0 |
| uid/gid | 0 |
| 地址型整数 | 0、缓冲区地址、2^30 |
| 其他整数 | 0、1、−1，以及词表中的前 4 个枚举值 |

- **校准运行**：全部候选在当前版本的 riscv、arm64、x86_64 内核上各运行 1 次（执行器为上一轮的 v2，不改）。校准只用当前版本，不用任何样本组的内核，不看任何缺陷的结果。
- **选择**：
  - 某个候选在至少两个架构上返回非错误结果（规整后不是错误码、`timeout`、信号或 `noresult`），算作“合法”；
  - 每个系统调用从合法候选中按编号取前 2 个；
  - 没有合法候选的，取在至少两个架构上返回相同错误码、且该错误码不属于 {EBADF、EFAULT、EINVAL、ENOTSOCK、ENOTDIR、ENOTTY、ESPIPE、EOPNOTSUPP} 的候选中编号最小的 1 个；
  - 仍没有的，取第 1 个候选。
  - 逐个系统调用记录它的基础用例属于哪一类。
- **raw_nr** 的基础用例：编号取表尾 +0（各架构上都无效），其余参数为 0。

## 三、变异（规则写死）

- 每个用例从该系统调用的基础用例中随机取 1 个，再随机改 1 处（概率 2/3）或 2 处（概率 1/3）。
- **可改的位置**：每个参数，以及基础用例中各结构化缓冲区的每个标量字段（不含位域、数组、内嵌结构体）。所有位置等概率抽取，不重复。
- **新值**：
  - 改参数时，从该参数可用的来源中等概率选一个来源，再从中取值。来源有：通用取值表（同前几轮）、词表（枚举值按位或 0～2 个标志位，同上一轮 C2）、资源（参数名在资源表里时）、新的结构化缓冲区（参数是结构体指针时，标量字段随机改 1～2 个，同上一轮 C1）；
  - 改结构体字段时，按字段名和类型的参数类取通用取值（整数）。
  - 区间模板：有“地址＋长度”参数的系统调用，模板也算一个可改的位置（none、occ、adj 三选一）。
- **G3s 的提示**：改到一个有提示的参数时，以 1/2 概率取提示值（上一轮裁剪后的提示），否则按上面的来源。

## 四、评价

- **三组**（各 1000 个用例 × 种子 1、2、3）：G0s 均匀轮转全集；G2s 目标为上一轮排序后的前 40 个系统调用（80% 用例在目标中）；G3s 目标同 G2s，加提示。
- 23 个内核各运行 3 次。判定、检出、人工确认规则与前几轮相同。
- **关键条件覆盖**：本轮的 `diagnosis_conditions.md`，在生成正式用例前写定并记 SHA。
- **参考线**：G2s、G3s 中较好的一组，其确认检出合计大于上一轮 G2m（7），并且 B467 或 A101 在该组至少 2 个种子中被检出，记为“单点变异有增益”；否则记为“未显示增益”。其余对比只描述。
