## 对根整理结果的验收建议

1. 不把“矩阵工作单元”和“独立缺陷”混用；八项 = 冻结十二条中六条 + 两项旧机制条目。固定十二条的 6/5/1 不变，新增确认与独立阳性均为 0。
2. 六条新样本的正式纵向五项、横向候选一项已有逐项报告依据；两项旧条目若要显示纵向，应标 `report_level_inference` 或“暂定”，不能声称本轮逐卡原物复核已完成，也不据八行算纵横向缺陷比例。
3. CPU 架构与平台/设备标签分栏。Btrfs/virtio 的 CPU 架构 unknown；ARM SMMU 是设备/模式证据，不能只凭“ARM”补 CPU 标签。ARM64 热插拔报告不证明所有可用 RISC-V 配置均触发。
4. 形成侧允许联合形成、unknown、待定；源码检查位置、当前提供/消费位置不等于历史引入侧，修复侧也不是正确侧的唯一标准。
5. 所有链接只作为现存报告的引用文字。报告中已有文档或原型结论不能升级为本轮直接规范裁定/原始运行复现；NUMA仍不足，KUnit机制卡没有补出八主项的日期或形成侧。

结论：有限报告层五维整理可通过，但八项完整五维统计仍不成立。最直接的空缺是首次实际发现日及旧两项逐卡形成侧/关系编码；自动检查是否能补齐这些研究问题须另列，不以本轮覆盖表替代检测试验。
