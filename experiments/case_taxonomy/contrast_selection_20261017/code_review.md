# N2.1 有限对照选择器独立审查（2026-10-17）

审查范围：`linux_bug_analyze/contrast_selection.py`（最终复核 SHA-256 `f6f1d5a0580146fde3ce2fa9d46a68a6270730c7947714bee9c037af9ef91b96`）、`tests/test_contrast_selection.py`、本阶段 `protocol_pre.json`、`example_pool.json`、`example_provenance.json` 和 `selection.json`。未读取既有运行结果、事件或模型回答；本审查也未证明任何内核运行结果。

## 结论

就**输入均由外部审阅并如实填写**的有限池规划而言，当前实现与预登记规则基本一致，没有发现阻止本轮已读示例进入下一阶段回放的代码缺陷。`eligible` 和 `selected` 仅表示机器检查通过了已声明的元数据条件，不是“配置合法”“语义相同”“发现缺陷”或“正常对照”的自动证明。示例来自已读旧案开发材料，并非独立样本。

代码要求：同一 revision、不同规范化架构名、相同目的与公共消费者的接口/操作/阶段/对象角色、相同抽象执行上下文、声明为 `legal` 的适用性、必要配置值、归档构建及同阶段适配器、至少一项经声明审阅的提供者语义特征差异。未知适用性进入 `legality_not_established`，不会被命名为正常。配对数和费用预算有明确拒绝原因；输出始终标记 `runtime_truth=not_evaluated`。

## 审查中发现并已修正的问题

1. 初版可将 `architecture` 等身份字段伪装为 `contrast_features`，仅凭架构名差异选出一对。现版拒绝显式架构名、路径、签名、版本及结果标签等特征名，连提供者的附加 feature 键也检查；合成反例返回 `invalid_contrast_features`。这只封堵了明确命名的泄漏，任意换名仍需语义审阅，协议和代码注释已说明。
2. 初版 profile review 的摘要未绑定 `id` 和 `cost`，因此费用或用于平局排序的身份可在原审阅后改变。现版把除 `review` 外的全部 profile 字段纳入摘要。将示例 P03 的 `cost` 从 1 改到 2 而不更新审阅时，P03 被 `profile_review_missing_or_mismatched` 排除。
3. 后续复核发现纯空白作用域值与常见架构别名边界；现版 `_text` 拒绝纯空白，`s390/s390x`、`x86_64/amd64`、`arm64/aarch64` 等已知别名归一后不能构成跨架构配对。别名表不是 ISA 同一性的完整证明，未知标识仍依赖外部审阅。

最终版的 28 项方法单测在本审查中全部通过。另用当前示例输入重新调用选择器，逐字段所得结果与保存的 `selection.json` 相同：仅 P01/P03（相同旧 revision 的 s390/x86_64）被选中，差异为 `qualification_domain` 和 `preparation_phase`，合计费用 2；修复版 P02/P04 没有被当作排序优先级或自动正常对照，跨 revision 配对被排除。这仍是对**人工填写的特征**进行规划，并非 N1 自动抽取了提供者语义。

## 使用边界与后续核验

- `researcher_review`、`legal`、配置验证状态、构建状态、特征值和引用路径均由调用者提供。摘要能发现记录漂移，却不核实引用足以支持逐字段语义，也不验证配置/镜像文件本身或审阅者身份。示例 provenance 明确写为助手根据已读材料整理，并非独立专家裁定；报告不能写成“已由人类专家确认”。
- 示例把不同架构的机器类型、CPU 型号与启动参数归并到相同的抽象 `execution`。这种同用途等价性是针对该狭窄场景的人工判断；元数据相等不能替代实际可启动、可达同一消费点的验证。已保存的 `archived_built` 也只描述历史构建记录。`pre_irq_disable_content_sample` 不等同于精确的首次内容消费或期间稳定性。
- 黑名单只能拒绝已知显式身份/结果键；如果把架构、路径或旧/修复状态改名成看似语义特征，程序无法识别。新场景必须逐项审阅特征定义和提供者赋值。特征是否适用于同一对象、同一生命周期时点，不能凭字符串及摘要判定。
- 平局使用 seed 和 profile ID 散列。示例 ID 为中性 P01–P04，且只有一个合格配对；推广时应保持 ID 中性，避免由含标签的 ID 间接影响平局。协议所说“不按架构或修复标签排序”应按此边界解释。

因此，N2.1 可作为下一步**只回放已保存选择的旧案两格**的计划输入；回放观察、同阶段可达性、真实语义契约及独立样本表现须另行验证，不能由本审查或该选择结果推出。
