## 事实与结论分层

- 格式载体：定宽字段注解、显式 API 格式参数、本地 helper 实现、人工消费者/外部规范；无端序注解的 `u64` 只给出源码类型，不能证明外部字节格式是主机序。
- 实际操作：按 occurrence 区分字段读取、字段写入、输出指针传参、固定标量 sizeof 非求值引用。复杂/VLA 表达式、别名、阴影、条件预处理或解析不唯一保留不足。
- 值域：仅支持静态函数在当前保存文件中的直接调用及简单无重复整数字面量宏。其结果是局部可见调用事实，不证明完整配置或实际运行可达；零值不制造字节差异。
- 模式与条件：模式标志出现和词法 guard 属源码事实；实际 ring flags、运行路径、固件/磁盘外部规范及支持的大端配置仍由人工证据说明，缺失保持 unknown。
- `candidate/normal/insufficient/not_value_read` 只评价受支持的局部操作；不由版本名称、是否出现转换、补丁形状或缺陷修复标题赋真值。机器和人工栏分开，引用完整性不认证语义。

## 验收

- 八个“接口 × 修订”记录绑定版本、源码原文、行号、SHA-256、Git blob，保留目标与正常/非消费对照。
- ocfs2 原始 mask 读取为条件候选、对应转换为局部 normal；同条件的其他访问不能被转换覆盖，零判断为局部 normal。
- PWM 保留旧类型候选，同时提取可见零值调用，不将它提升为该调用的字节故障。
- SMB 分离 sizeof 和 API 输出；小端 selector 及本地实现有同版来源，两版指针 cast 不被称为端序变化。
- ath12k 提取实际读方向及 helper/字段声明，记录 swap 源码事实；父版外部格式和实际模式仍不足，不用修复声明补父版证据。
