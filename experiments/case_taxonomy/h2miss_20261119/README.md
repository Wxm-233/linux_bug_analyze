  - **C SIMD 可用性**：1 个（poly1305；上一批留出集漏报里也有一个 arm64 SIMD 的）；

## 建议的顺序

1. **A 线性映射地址**（地址类别，类型一致性检查）：形态清楚，覆盖 2 个，历史上同类修复多（如“改用 `__pa_symbol`”“vmalloc 地址不能用 `virt_to_page`”），容易挖到独立样本。
2. **B 能力判断**（实现一致性检查）：与师兄的“效果依赖”最接近。架构实现在某个能力不满足时什么都不做却返回成功，公共代码必须先查这个能力。
3. **C SIMD 可用性**（调用上下文检查）：需要把扫描范围扩到架构的加密代码。
4. **D compat 指针数组**。

每条规则都按老规矩做：先写判据，再在开发样本上能报出，然后看当前版本的候选，并找独立的历史样本测召回。做完后整体再跑一次封存集，只看汇总。
