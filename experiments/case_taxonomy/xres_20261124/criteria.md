## 三、做法

用 libclang（clang 18）按编译数据库解析 F 所在的编译单元（带详细预处理记录），在 F 的语法树上，对每个调用了第一轮边界函数 G 的位置 L，抽取下面四种资源：

1. **入参资源**：G 的每个实参。
   - 记录类型：G 是函数时用 G 的形参类型；G 是宏时，用实参里变量在 F 中声明的类型。
   - 记录来源：F 的形参、F 的局部变量（同时记它的初值或赋值来自哪个调用）、对指针解引用、结构体字段、全局变量、常量。
2. **返回值资源**：G 的结果（L 处最外层表达式的类型）在 F 里怎么用：
   - 作为条件（`if`/`while`/`for`/`?:`/`&&`/`||`）；
   - 赋给变量（记变量名）；
   - 作为实参传给另一个调用（记被调名）；
   - 写入内存（解引用或字段赋值）；
   - 作为返回值；
   - 丢弃。
3. **常量资源**：F 里展开的对象式宏，定义在 `arch/` 下或第一轮的架构层条件分支里（例如 `PAGE_SHIFT`、`HPAGE_PMD_ORDER`、`PAGE_NONE`）。
4. **共享状态资源**：G 是带函数体的函数（例如头文件里的 `static inline`）时，G 体内读写的全局变量。

**资源分类**按类型和名字机械判定，与资源文档的章节对应：

| 资源种类 | 判定 | 文档分类 |
|---|---|---|
| 页表项 | `pte_t/pmd_t/pud_t/p4d_t/pgd_t` 或其指针 | 四、页表项 |
| 页保护属性 | `pgprot_t` | 四 |
| 交换项 | `swp_entry_t`、`softleaf_t` | 四 |
| 页帧号、物理地址 | 名字含 `pfn`；`phys_addr_t`/`resource_size_t` | 七、指针和地址 |
| 虚拟地址 | `unsigned long` 且名字含 `addr`/`address`/`start`/`end`/`va` | 七 |
| 对象指针 | `struct page/folio/vm_area_struct/mm_struct *` 等 | 七 |
| 数值 | 其他整数，含名字含 `size`/`len`/`order`/`nr`/`count` 的 | 六、数值 |
| 常量 | 第 3 种资源 | 六 |
| 全局状态 | 第 4 种资源，以及来源为全局变量的入参 | 三、内存里存的数据 |
| TLB/缓存效果 | G 的名字含 `flush`、`tlb`、`update_mmu_cache`，且不返回值 | 五、TLB 和缓存 |
| 能力判断 | G 无实参（或实参都是常量）且返回值作为条件 | 十、功能能不能用 |
| 其他 | 以上都不是 | — |

**引擎覆盖表**（事先写定）：页表项、页保护、交换项 → P1、XV、EC；页帧号、物理地址、虚拟地址、数值 → WT（位宽）、EC（截断）；常量 → ORD（只覆盖阶数类）；TLB/缓存效果 → TLB；能力判断 → 无（WK 只看弱定义覆盖）；全局状态 → 无；对象指针 → 无；调用上下文（每个边界调用点都有）→ CTX。
