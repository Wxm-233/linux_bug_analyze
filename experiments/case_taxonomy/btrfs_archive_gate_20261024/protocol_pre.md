# Btrfs归档重放原件门禁：执行前协议

本轮不调用Claude或其他项目模型，不做新源码语义分析，不新增内核运行。复用分层接线的12份登记，固定其外部SHA和通用核心SHA；增加可复用的归档读取门禁。冻结SHA是研究者本地信任锚，不是独立签名或语义真值。

先核登记文件的外部SHA，再核每份引用文件的实际字节SHA、真实行数、引用范围及版本登记；同一路径在一轮只读取一次，判定对应该字节快照，不承诺文件此后不变。任何错误均拒绝进入关系判定。原通用核心和旧结果不改。

预期原件重放保持原12项结果；显式标记的内存变异控制覆盖原件变更/缺失、审核变更、登记及SHA一起修改、引用越界、原件行数不足、未知文档、错版本。不得把这些控制记作新运行、独立样本或新缺陷。外部信任锚被更换不在保护范围，不能以哈希替代研究者语义审核。C与whole_path继续不足。
