- 简单补丁30个；没有超过300行的。
- 参照架构：arm64最多，RISC-V其次（LoongArch跟进RISC-V的配对共14个），x86较少。

## 使用时要注意

- **目标架构以LoongArch为主**（33/42）。本研究关心RISC-V，但LoongArch跟进RISC-V或arm64的配对，同样是“把上游补丁迁移到另一个架构”。其中参照为RISC-V的14对，可以检验在RISC-V上总结的修复策略能否推广。
- **第二批偏向说明直接点名参照的样本**：26对中多数在说明里写了参照提交，迁移可能比实际情况容易。报告结果时，要把第一批和第二批分开给出。
- 新功能的配对改动较大，第一轮回放实验可以先用简单补丁（30对）。
