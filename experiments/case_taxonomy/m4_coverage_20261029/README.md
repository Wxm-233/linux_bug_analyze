## 解读

- “修复位置±5行”的机械指标会高估：5个机械覆盖中2个是碰巧在附近的无关点。
- 漏检的结构原因：缺陷关系与修复位置不在同一处（shmem）；大文件中变化点被截取（C07，V1多达121个）；驱动不在追踪上下文构建（C15）；关系由修复新增、父版无标记（C18，及登记时已预见的s07类）；父版只有与缺陷无关的变化点（C01）。
- 对未用于设计的用例，程序定位只覆盖到1/5（不截取2/5）。即使模型在覆盖到的点上全部写对，M4在这类缺陷上的上限也很低；调大截取上限会让每样本变化点数上百，模型调用规模与噪声随之上升。
