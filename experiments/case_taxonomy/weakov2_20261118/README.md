4. **定位**：这是一条“精准、低噪声但覆盖窄”的专项检查，主线只有 3 条非 alt 候选。它对整体召回的贡献有限，主要价值在于缺陷合入时就能拦下这一类问题（18a4e5cf 在 v6.11 合入当时即可报出）。
