## 正式E1的成本估计

131个A0准入样本，每个1次调用；按试点约15k—45k输出token、3—6分钟/次，顺序执行约7—13小时，合计约2—6百万token（每次调用独立1M额度口径）。超过160KB的样本会截断并登记。付费调用规模较大，须用户确认后启动。

## 边界

试点只验证流程与交付，不评价候选正确性；E1结果仍需程序核验、研究者复核及修复参照对比。独立正例/正常仍0/0。
