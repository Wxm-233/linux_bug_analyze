- 两个失败点都具体：（1）“跨架构相关”需要识别**隐式**依赖（修改处使用了在`include/`中有`#ifndef`回退的宏，或用`defined()`检测这类宏）；（2）A1需要只比较同单位的量，并允许纳入“展开链包含所用宏”的上限宏（反向链，如`MAX_PAGECACHE_ORDER`→`PREFERRED_MAX_PAGECACHE_ORDER`→`HPAGE_PMD_ORDER`）。
