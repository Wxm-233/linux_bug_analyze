### 源码层发现

ARM64可在尚无ACPI processor handle等条件下延后CPU device注册；公共SMT enable按present集合及多项许可条件启动CPU，成功后取得该CPU device并更新状态/发事件。因此需要核对“进入实际消费的CPU”是否已有同对象的有效device，而不是把present、online和device存在当同一件事。

x86 generic注册路径可给出积极但有前提的保证：成功注册后发布同CPU索引对象，且索引/possible合法、期间未注销时，getter可取得该对象。注册循环仅记录失败，不能由循环存在推出全部present对象都已成功注册。

这是一条值得保留的**条件性机制候选**。本组未闭合合法非空触发、完整阶段及正常实例，不能据此声称ARM64实际出错、x86已经证明正常或发现新缺陷。
