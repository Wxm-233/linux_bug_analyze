## 一、目标与边界

整版扫描表现有九列：序号、检查类、引擎、优先级、文件、行、函数、受影响架构、特征。“点位”已经有了（文件、行、函数），本轮补三列：

- **关键资源**：这个点位操作的是什么（哪个值、哪个页表项、哪段映射、哪个架构钩子）；
- **要观察的性质**：这个资源要满足什么，才算各架构语义一致；
- **不算失配的条件**：满足什么就说明这条候选不是缺陷，审查时照着核对。

**只改输出，不改检出**：九个引擎和规则一行不改，不重跑引擎。三列完全由每行已有的字段（引擎、特征、函数）按下面第二节的规则机械生成，不逐条手写。

## 二、各引擎的填法（来源：各轮 README/判据里对形态的定义）

记号：特征按 `|` 切开，`$1`、`$2`… 依次是各段。

| 引擎 | 形态 | 关键资源 | 要观察的性质 | 不算失配的条件 |
|---|---|---|---|---|
| WT（widthtrunc3） | A 窄化（`A|arg:F#i|e` / `A|assign:x|e` / `A|return:return|e`） | 传给 `F` 第 i 个参数 / 赋给 `x` / 作为返回值的 `e` | 在 32 位架构上，`e` 的值放得下目标类型，高位不被截掉 | 在所有架构上 `e` 的取值都不超过目标类型的范围 |
| | B 移位溢出 | 同上（移位表达式 `e`） | 移位在 32 位宽度里计算时不溢出 | 移位前已扩到 64 位，或结果在 32 位内放得下 |
| | C 掩码截断（`C|mask|e`） | 掩码运算 `e` | 掩码与被掩的值同宽，不丢高位 | 掩码已按被掩值的类型扩宽，或被掩值的高位本来为 0 |
| ORD（orddom） | 常量名 S（可多个） | 由页大小派生的阶数/大小 `S` | 在每种“架构 × 页大小”下都不超过页缓存上限 `MAX_PAGECACHE_ORDER` | 所有组合下都不超过上限，或使用前已和上限比较 |
| P1（reachgap） | `A|e` | 页表项 `e`（交给 `A`） | 调用 `A` 时 `e` 是 present 项（`A` 只对 present 项有定义） | 调用前已确认 present，或这条路径上不可能出现非 present 项 |
| XV（xvdom/xvlift） | `dom|A|e`、`lift|H@k|A|e` | 页表项 `e`（交给 `A`；lift 时经辅助函数 `H` 的第 k 个参数传入） | 按 `A` 在 `xvdom_20261116/table2.json` 的组：R、MG 组要求 `e` 是 present 项（MG 是修改接口，用错会把项改坏）；S、MS 组要求 `e` 是非 present 且非空的交换格式项 | 调用前已按该组的要求确认了项的种类 |
| TLB（tlbhook） | T2 | 内核页表（`init_mm`）里新建的映射 | 建好后本函数或向上 3 层调用者调用了 TLB/缓存刷新钩子，新映射在需要刷新的架构上立即可见 | 调用链上有刷新，或该映射在被访问前已由其他机制保证可见 |
| | T3 | `flush_cache_page` 的刷新范围 | 第 3 个参数是页框号，大页按整块刷新 | 参数确为页框号且范围覆盖整个映射 |
| | T1a/T1b/R1（架构侧，带架构名） | 该架构的刷新钩子（R1：`$4` 所刷的地址段） | 钩子对这段映射真正生效，与同一架构的其他钩子语义一致 | 该架构确实不需要这项维护，或钩子已覆盖这段地址 |
| WK（weakov2） | `WK|f|arch|eff|kind|cond` | 弱定义 `f` 的默认效果（调用 `eff`） | `arch` 的覆盖实现在所有路径上都完成这项效果（conditional-effect：只在 `cond` 时才做；early-return：`cond` 时提前返回跳过） | 条件不满足的情形在该架构上本就不需要这项效果 |
| XA（xvatom2） | 规则 B | `f` 收到的页表项 | 架构实现对非 present 项的假设（`VM_BUG_ON(!p?d_present)`）与公共调用方实际传入的项一致 | 所有公共调用方都只传 present 项 |
| | 规则 A | `f` 对页表项的读-清操作 | 读和清是原子的 | 调用方持锁或该架构不会并发修改 |
| CTX（ctxeff） | `hook|arch|sleep|…`、`…|ipi|…` | 架构钩子 `hook` 的 `arch` 实现（调用点 `$4`） | sleep：在调用点的上下文里调用它不会睡眠；ipi：不会发 IPI 并等待 | 调用点实际不在原子/关中断上下文，或这种调用走不到睡眠/IPI 路径 |
| EC（ec10） | 规则 4 `a→b`（true/false） | 经 `$3` 处理后的页表项（`构建` 上） | 观察 `$5` 的结果与多数架构一致（多数为 a，本构建为 b） | 差异属于架构允许的实现差异，公共代码不依赖它 |
| | 规则 5（改变/保持） | 调用 `$3` 前后的页表项 | `$3` 对 `$5` 的影响与多数架构一致（多数：前者，本构建：后者） | 同上 |
| | 截断 `截断:字段` | `$3` 编码的 `字段`（交换项偏移、页帧号等） | 合法范围内的值编码后再解码能原样读回 | 该架构的合法取值本来就在编码宽度内 |
