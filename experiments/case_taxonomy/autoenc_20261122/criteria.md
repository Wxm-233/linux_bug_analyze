# 判据：编码一致性引擎第一轮——自动发现接口与定律（autoenc_20261122）

2026-11-22，Claude。用户：“开始第一轮”（方向：逐位求值做成整版扫描里的自动引擎，暂名 EC，归“实现一致性检查”）。写于实现和运行之前。

## 一、原则

- **输入只有内核版本和构建清单**。不给任何人工的约定清单、接口清单或函数对；前几轮人工找出的义务只在最后用来检验“自动挖掘有没有把它们找回来”，不进入挖掘过程。
- 引擎内置的只有**通用规则**（对所有接口一视同仁）：
  1. 接口命名空间：页表项与交换项相关的标识符前缀（`pte_`、`pmd_`、`pud_`、`pfn_`、`__swp_`、`__pte_to_swp`、`__pmd_to_swp`、`swp_`、`softleaf_`、`make_`、`PAGE_`）；
  2. 类型模板：用 clang 试编译带类型的小包装，按能否通过把接口分成构造、观察、修改、编码、解码、保护常量；
  3. 参数域规则表：按参数名的词（`type`、`offset`、`pfn`）取公共常量给出合法域（交换类型 `< MAX_SWAPFILES`；交换偏移 `[1, 2^min(32, 编码容量))`；页帧号 `[0, 2^(MAX_PHYSMEM_BITS - PAGE_SHIFT))`，没有 `MAX_PHYSMEM_BITS` 时退到 `SWP_PFN_BITS` 或 `phys_addr_t` 宽度，并记为“回退域”）。
- 这三条规则与具体约定无关，写进引擎、记 SHA，本轮之后不为了“找回某条义务”而修改；确需修改要写修订，并说明会影响哪些已知结果。

## 二、流程（全部自动）

1. **发现**：在 `df2908090cda` 上，从 `arch/*/include/asm/` 收集在 ≥ 2 个架构目录中各自定义（宏或 `static inline`）的、属于上述命名空间的标识符；从 `include/linux/{pgtable.h,swapops.h,leafops.h}` 收集同命名空间的公共内联函数。
2. **分类**：在 20 个构建上逐一试编译类型模板（`T→T` 修改、`T→标量` 观察、`(标量, pgprot)→T` 构造、`(标量[, 标量])→交换项` 交换构造、`交换项→T` 编码、`T→交换项` 解码、`交换项→标量` 字段观察、`→pgprot` 常量；T 取 `pte_t`、`pmd_t`、`pud_t`）。通过的才算该接口在该构建上的签名。排除原始值访问（`*_val`）和需要额外对象（如 vma、mm、指针）的接口。
3. **组合**（深度限制）：
   - 交换族：交换构造 → 编码 → [0 或 1 个交换修改] → {有效/空判断、交换标志观察、解码 → 字段观察}；
   - 映射族：`pfn_T(pfn, prot)`（prot 取各构建都有的 `PAGE_*` 常量）→ [0 或 1 个修改] → {观察}。
4. **求值**：每个组合在每个构建上用逐位求值器（`swapsym_20261121` 第二版，导入不改）在参数域上求值，得到“行为”：恒 0、恒 1、等于某参数（逐位）、等于某参数的低 k 位（记第一个不同的位）、其他、不支持。运行时判断逐组合求值。
5. **多数表决出定律与偏离**：同一组合键（接口名的组合）在所有能编译的构建上比较行为。≥ 3 个构建可比、且一种行为占多数（> 50%）时记为定律；与多数不同的构建记为**偏离**。只有“等于某参数的低 k 位”且多数是“等于该参数”的偏离给出具体反例（参数取 2^k），并用 clang `-O2` 折叠复现。
6. **出候选（本轮只出表，不接入 scan3）**：偏离 → 候选行（构建、架构编码所在文件、组合、多数行为、偏离行为、反例、域来源）。回退域上的偏离记优先级二。

## 三、门槛（本轮通过条件）

- **G1 找回**：不提供人工清单，自动结果必须包含前几轮人工检查的全部对象：普通交换项 O1/O2/O3、PFN 交换项 P1/P2/P3（三种迁移类型；hwpoison、设备私有项按配置）、PMD 交换项 O1～O3（有 PMD softleaf 的构建）；并且 **arm_lpae、mips32xpa、ppc44x、mips64 的页帧号截断自动作为偏离出现**，普通交换项在 20 个构建上不出偏离。缺任何一项，本轮不通过，写清缺在哪一步。
- **G2 对账**：所有给出反例的偏离，clang 复现一致；有一处不一致就不通过。
- **G3 规模**：报告发现的接口数、组合数、定律数、偏离数（按族、按优先级），以及映射族里 pgassert basic tests 的断言类型（例如 `pte_young(pte_mkyoung(x))`）是否作为定律出现。不设数量门槛。
