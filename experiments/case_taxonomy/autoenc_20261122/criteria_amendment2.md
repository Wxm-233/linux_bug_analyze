# 判据修订 2：组合与求值的通用规则（autoenc_20261122）

2026-11-22，Claude。写于求值之前（已跑完发现和 x86_64 的分类：170 个接口有签名，20 个构建的分类在跑）。下列规则都是结构性的，对所有接口一视同仁，不引用任何具体约定。

1. **层级一致**：名字以 `__` 开头的接口属于架构层，其余属于公共层。一个组合内只用同一层的构造、编码、解码和字段观察。（否则会把架构格式的交换项传给公共函数，类型能过，语义没有意义。）
2. **两族的修改与观察**：
   - 交换族只用名字里带 `_swp_` 的修改和观察，加上该页表项类型的“有效/空”判断（`<T>_present`、`<T>_none`）；
   - 映射族不用带 `_swp_` 的接口。
   （present 专用接口用在交换项上，是 P1/XV 已在检查的内容，本引擎不重复。）
3. **参数域再受公共层宽度限制**：交换构造的偏移/页帧号参数，合法域的位数还要不超过“公共层自己能保持的位数”，即不经过架构编码时，该层的字段观察对该层构造能原样读回的位数。这个位数由求值器自动算出。
4. **编码容量**（判据第一节域规则里的“编码容量”）：对每个“构造 → 编码 → 解码 → 偏移观察”组合，偏移取公共层宽度、跳过有效/空判断，从第 0 位起数能原样读回的位数。
5. **求值方式**：分类得到的每个包装函数（每个接口一个）在解释器里串起来调用，中间结果缓存复用。只有出现偏离时，才生成对应的 C 组合交给 clang `-O2` 折叠复现。运行时判断按真假组合各求一遍：各组合行为相同取该行为，不同记“依赖运行时”，不参与多数表决。
6. **优先级**：
   - 一：交换族中“分类”偏离（有效/空判断与多数不同），或者在非回退域上出现的“低 k 位”截断；
   - 二：其他偏离，以及只在回退域上出现的截断。
7. **常量**：`MAX_SWAPFILES`、`PAGE_SHIFT`、`PMD_SHIFT`、`PUD_SHIFT`、`MAX_PHYSMEM_BITS`（是否定义）、`sizeof(phys_addr_t)` 都由 clang 在各构建上折叠得到。
